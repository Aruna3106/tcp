TCP Flow & Error Control Simulator

Simulate TCP data transmission between a sender and receiver and observe acknowledgements, retransmissions, sliding windows, packet loss recovery, flow control, and error control mechanisms.

Project Objective

This simulator demonstrates TCP communication by transmitting packets between a sender and receiver. Different receiver window sizes and packet errors are introduced to observe how TCP manages flow control and error recovery.

Features

  • TCP Flow Control Simulation
  • Sliding Window Protocol
  • Receiver Window Management
  • Packet Loss Detection
  • Acknowledgement Tracking
  • Retransmission Mechanism
  • Performance Dashboard
  • Protocol Comparison
